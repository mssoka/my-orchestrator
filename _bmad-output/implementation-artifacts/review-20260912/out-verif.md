### stuckCheck's N04 typed-union fallback (`statusFor`) is never executed under a failed PR-tick inventory — a regression there silently kills ALL PR-tick alerting

- **Changed surface:** `liveStatuses()` now returns a typed union; `stuckCheck` must handle the `{ok:false}` case via the `statusFor` fallback — `.pi/extensions/nefario-watch.ts:713-716`.
- **Impacted consumer or site:** the prTick alert pipeline — `stuckCheck()` runs at `.pi/extensions/nefario-watch.ts:1422`, immediately before the single `sendMessage` at `:1424-1425` that delivers ALL PR-tick alerts (CI FAILING, MERGE CONFLICT, REVIEW, PR MERGED/CLOSED, Perkins-pending, dream, round-debris, stuck). `prTick` has no catch — only a `finally` that resets `prTicking`.
- **Existing test evidence:** `test/nefario-sensor-safety.test.ts` N04 cases (n04a–n04e) drive inventory failures through `world.paneTickHerdr` (the PANE tick's read) only. The PR-tick inventory (`world.herdrAgents`, read by `roundDebrisCheck` and `stuckCheck`'s `liveStatuses`) is never set to a failing value in any test world — its only occurrence as a value is the default `{code: 0, …}` at test line 81. Mutation leg executed: replacing `statusFor`'s union handling with an unguarded `live.statuses.get(pane) ?? infoStatus ?? "unknown"` (throws TypeError when `!live.ok`) leaves BOTH suites fully green (13/13 sensor-safety, 8/8 conflict).
- **Missing verification:** an assertion that a prTick with tracked (non-done) jobs AND a failing `herdr agent list` completes without throwing, emits the health note, and still delivers its other alerts.
- **Demonstration:** the mutation above ships green. In production, any herdr-inventory failure during prTick makes `stuckCheck` throw; the trailing `sendMessage` never runs, so every PR-tick alert class (merge close-outs, CI failing, conflicts, review verdicts, Perkins dispatch triggers) is silently dropped for the duration of the herdr outage — exactly the N04 failure mode the change exists to make safe, on the tick the suite doesn't cover.
- **Consequence:** a one-line regression in the union handling converts a herdr blip into total PR-sensor blindness with zero test failure.
- **Disposition:** `patch` — add one case to `test/nefario-sensor-safety.test.ts`: `jobs: [{id, pane_id, status: "working"}]`, `herdrAgents: {code: 1, stdout: ""}`, run `prTick`, assert a `debris-pane-inventory`/health note fires (or at minimum that a co-present review alert still delivers) — fitting the suite's existing FakePi world shape.
