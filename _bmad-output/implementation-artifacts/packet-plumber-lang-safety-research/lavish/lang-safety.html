2 · Falsify the premise — would Rust / Godot have prevented THIS bug?

Safe Rust — YES, compile time

The bug is literally the Rust Book ch.4 example: two values sharing one heap buffer, both dropped = double free. Assignment MOVES ownership; using the moved-from value is error E0382. There is no spelling that compiles into tonight's bug without unsafe or a hand-written aliasing Clone — both visible in review.

Godot (GDScript) — YES, runtime model

RefCounted objects auto-release; a script cannot perform the invalid free. Residual families: cycle leaks (documented), orphaned nodes, stale shallow duplicate() reads (logic bug, not corruption), dangling signals, engine C++ bugs.

Odin + practice — NOT at write time, YES at CI time — PROVEN

Odin has no compile-time ownership (by design — on the record). But Tracking_Allocator fires a bad-free callback with the source location on the FIRST offense. Not hypothetical: #108's Perkins mutation leg used it — removing the fix lines produced deterministic bad-frees at box.odin:44-45 across a 5-window scripted leg. The landed 57-array alias-pin test closes the family at CI time. One sharp nuance: the allocator lives in the slice header, and the value copy carried the LIVE allocator — that's why the aliased free succeeded silently through the correct allocator; the feature that guards cross-allocator frees is what let this one through.

The honest inversion — what Rust/GC do NOT close
✗ Logic bugs (spool arithmetic, era caps, routing) — identical exposure
✗ Determinism discipline — map-iteration order / float rules stay convention in Rust too
✗ Leaks — safe Rust leaks happily (Rc cycles, mem::forget); same as Odin
✗ The predict-by-cloning design — same architecture; Rust just forces the real deep-clone cost
✗ unsafe renderer interop / FFI — a narrower hole re-opens the moment you wrap wgpu/raylib C
✓ One thing Rust uniquely adds: data-race safety (Send/Sync) — irrelevant today, load-bearing if threading ever lands
Verdict: the premise survives — Rust/GC genuinely prevent tonight's class. The decision-relevant correction: prevention is also purchasable in Odin for ~a day of work. So the real question is cost & risk to equal protection — §4.
