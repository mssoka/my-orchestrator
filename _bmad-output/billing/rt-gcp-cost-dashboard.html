Limitation — use-case attribution within iginsider
The iginsider project holds the Gemini API service (€191.44), and three different workloads call it: (1) RT Facebook ad-creative generation [business], (2) RT agent usage [business], and (3) personal YouTube content [Veo video + image gen]. GCP bills by project + service + SKU — it does not record which application/use-case made each call. So only the project boundary is cleanly separable (righttenantry = business; iginsider Gemini API = blended). Splitting the blended bucket into FB-ads vs agents vs YouTube would need your own application/usage logs (e.g. per-call tagging). Consequence: the true business share is ≥ 85.9% (the clean business floor plus the FB-ads + agents portions of the blended bucket) — it is not exactly 85.9%.

③ Cost-driver diagnosis — fixed compute vs variable LLM

Cloud Run · €583.62 (43%) · business

Fixed, always-on. Min-instances keeps instances warm 24/7 whether or not traffic arrives. CPU instance-billing is the dominant line: July alone was €126.65 CPU + €21.10 memory.

It is growing (€70.59 Apr → €144.16 Jul) as more services go always-on. Cost is not proportional to applications processed — it's mostly idle compute.

Billing CSVs don't split Cloud Run by service name; the agents vs main-app split needs per-service GCP metrics to pin exactly.

Vertex AI · €552.71 (40.7%) · business

Variable, per-call. The agents' Gemini LLM (reference checks + compliance). Spiked to €250.92 in May, then fell to €112.96 (Jun) and €43.27 (Jul).

✅ Retry-fix confirmed working. The May spike aligns with the pre-fix period; the −83% May→Jul decline shows the fail-fast-on-compliance-judge change is doing its job. Already done — not re-recommended.

Remaining lever: heavy use of Gemini Pro (Pro text output ≈ 5–10× Flash). Caching already in use. Note: agents may also drive a slice of the blended Gemini API bucket below — total agents-LLM = Vertex €552.71 + unknown part of Gemini €191.44.

Gemini API · €191.44 (14.1%) · blended

Triple-blended, unattributable from billing. One shared project (iginsider) serves RT Facebook-ad creative, RT agent calls, and personal YouTube. GCP records project + SKU, not which app made the call.

By SKU the bucket splits into Veo video gen €153.81 (€0.345/s, ~€20.7/min — most consistent with YouTube content) and Gemini image gen €37.63 (could be FB-ad creative or YouTube thumbnails).

To attribute use-cases, add per-call tagging in your apps and export to logs. The Veo/image pricing levers below apply regardless of which use-case drives them.
