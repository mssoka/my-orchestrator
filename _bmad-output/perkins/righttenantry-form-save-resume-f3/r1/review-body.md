### Blockers (1)

**B1 — Continue-link email builds tokenized resume/erasure URLs from the request origin** `[security]` — `server/src/application/draft_handler.gleam:291`
`handle_continue_link` derives the emailed base URL via `http_origin.canonical_origin(req)`. That helper prefers `x-forwarded-host` and trusts **any** host ending in `.run.app` (the charset guard only blocks markup smuggling). The endpoint is public: an attacker who controls any free `.run.app` hostname POSTs with the victim's email + the (semi-public) vacancy code, and the victim's genuine branded Resend email carries their live 288-bit continue/erasure token to the attacker's domain. One click exposes the saved application PII (via resume) or deletes it (via erasure). Every other `canonical_origin` use is response-local SSR canonical/OG tags, where poisoning only affects the requester's own page — this is the first use that persists a request-derived origin into email sent to a third party. The established emailed-link precedent is one file over: the confirmation email's `/erase/` link is built from `vacancy.origin_domain` via `email_client.build_entity_url` (`application_handler.gleam:2121`).
**Fix:** build the emailed base from `vacancy.origin_domain` via `email_client.build_entity_url`; keep `canonical_origin` strictly for response-local SSR tags.

### Warnings (11)

1. **W1 — Stage-2 reminder continue-link only reaches pre-minted-token drafts** `[acceptance]` — `server/src/application/sql/list_resumable_draft_tokens.sql:9`. The E2 seam (requirement 5) silently no-ops for the majority cohort. **Fix:** mint tokens for tokenless live drafts at reminder-prefetch time (`COALESCE(continue_token, <random>)` before the SELECT).

3. **W3 — Self-service erasure is silently undone by any still-open form tab** `[edge ×2 chunks]` — `delete_draft_by_token.sql:4` + `upsert_application_draft.sql:7`. A confirmed Art. 17 deletion is reversed without anyone knowing. **Fix:** tombstone erasure (`fields='{}'`, token NULL, erased marker the upsert's WHERE rejects), mirroring the strip-on-submit pattern in this same diff.
4. **W4 — Retention sweep deletes drafts on vacancy *archive*, contradicting the emailed "expires when the vacancy closes" promise** `[blind]` — `delete_expired_application_drafts.sql:8-14`. 5. **W5 — Unauthenticated draft-save has no volume bound** `[blind]` — `draft_handler.gleam:8-17`.
